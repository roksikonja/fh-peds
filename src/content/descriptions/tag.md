# Triglycerides (TAG)

Enter the **untreated** triglyceride value — i.e. measured *in the absence of lipid-lowering therapy*.

## Units

Accepted units:

- `mmol/L` — model-native unit
- `mg/dL` — converted using $1\ \text{mmol/L} = 88.57\ \text{mg/dL}$

The model uses the value in `mmol/L` internally.
